# Pitfall rules — read this first (every report builder and checker)

The prevention rules only. The full log with examples and run tallies is `claude/REPORT_PITFALLS.md`: open it only to look up an example. Checkers tag every correction `PITFALLS: <letter>:<short example>`.

**A. Chart data.** Every point is a real month-end close copied from a fetched source (Yahoo monthly Close, or digrin "Real price" — see I); never type, round or estimate a value. One basis for the whole series, matching the header price: splits adjusted, dividends not (a dividend-adjusted series is rebased to plain closes at the next refresh; an unlabelled one fails chart_audit for a named slug), spin-offs adjusted or labelled "not spin-adjusted". Run `py -3 tools/chart_audit.py <slug>`: 0 wrong points. After changing any point, sweep the text (prose, timeline, `events` labels, cards) for the old value and fix every month-end use. Compare price return with price return over the same window (SPY month-end close → banner-date close).

**B. Nothing after the banner date.** Everything price-dependent is recomputed at the banner-date close or removed. Every dated item ≤ banner date; a consensus page read later says "read <date>; latest action <date>". Check a stale-looking live figure against daily rows for the exact window.

**C. Sources.** Primary first (release, 8-K, 10-Q, proxy — sec.gov via WebFetch, no personal data in any request), then Reuters/Bloomberg/WSJ/CNBC/AP/trade press, then data sites. Aggregators, AI summaries and search snippets only *as* summaries, never the sole basis for a number or quote. Never: casino/gambling affiliates, DailyPolitical, crypto-exchange news, Substack or beehiiv newsletters, forums, TIKR/Quiver-only claims. No "polled by S&P Global" (or LSEG, FactSet) unless the fetched page names the poll. Class actions: "alleges", attributed to the filing firm.

**D. Quotes.** Quotation marks only for words read verbatim on a fetched transcript or release, with the speaker named there; otherwise paraphrase and attribute. No truncation inside a quote without an ellipsis.

**E. Entity facts.** Executives, deal status, ownership: the company's own site or latest filing, dated. Facts carried over from the previous edition are re-verified, not inherited. S&P add date from the S&P DJI release when findable; Wikipedia dates labelled. Index membership from the provider's list, not Wikipedia. Holders and stakes from 13F/13G/13D or the proxy, dated.

**F. Arithmetic, counts, superlatives.** Recompute every count, streak, superlative and % change from the page's data or a fetched series before writing it; if you can't compute it, don't claim it. Trailing P/E = header price ÷ the page's EPS (TTM) cell, never a data site's P/E field. A drawdown or multi-year return uses one basis and names it (closing vs intraday; price vs total return with dividends reinvested), with its start and end dates.

**G. Basis.** State the basis (GAAP/adjusted, fiscal year, source) beside every estimate; if sources disagree, show both or pick the primary and say why. A forward P/E names its EPS year; call it NTM only when the source does.

**H. Direction and cause.** Price reactions are close-to-close from daily rows, never intraday or after-hours headlines. Causes come from management's own words or are labelled as a reading.

**I. Data-site traps.** stockanalysis: the current session's row has no Adj. Close until settled — don't use it; live fields are intraday; fiscal-year labels can run a year ahead. digrin: header price stale (use the table); "Adjusted" is dividend-adjusted; "Real price" is not split-adjusted and can be back-adjusted for a spin-off — cross-check against Yahoo. Yahoo: close = split-adjusted, adjclose = + dividends; spin-offs appear as fractional "splits". Short interest carries its settlement date (latest published by the banner date), never the read date; date it, don't drop it. Data-site quarterly/TTM figures yield to the release. Date an analyst action from the ratings table or the firm's note, not the news article. Financial-statement figures (capex, cash flow, segments, debt) from the filing's raw text, never a WebFetch summary. Nasdaq calendar past dates lose the release time — confirm on the release. A ticker can be recycled: Yahoo ARTI.TO carries another security before the fund's 25 Mar 2024 launch — check the launch date on the issuer page and chart only from it.

**J. Build hygiene.** Title ticker matches the slug; `</head>` present; the P/E row labelled exactly `Trailing P/E`; `.fin-scroll` wrapper kept; existing accent colours stay (red-accent pages: 200-day MA #cbd5e1); no literal closing style tag inside a CSS comment; no mojibake; delta box `tg-d--fix` whenever the edition corrects the previous one. Yield Context cell: `dividend ÷ header price` and no other `$x ÷ $y` (the post-pass reads the first one: PEP, GM, NUE). No bare URL in visible text: name the source ("State Street Q3 2026 earnings release, sec.gov") or make the URL a link with that name as its text — an unbroken 100-character URL pushes a phone page sideways (STT, 22 Oct 2026).

**K. Card lines** (card runs only): see `claude/briefs/CARDLINE.md`. **L. ETF / crypto / bond reports**: see `claude/briefs/BUILD_ASSETS.md`. On every page: no hedge or process caveats ("not sourced", "not confirmed", "our reading" as a doubt marker, "our inference", "our application of the rule") — source it or remove the sentence. Asset reports: closes from Nasdaq/Yahoo daily rows, not issuer price APIs (they can lag a day); current fund/index names from the latest prospectus supplement; read a third-party series' licence note before building on it (Moody's on FRED: consent required). Every build: read the company's releases from the last print to the banner date (approvals, deals, designations land between results). Non-US listings: title = Yahoo exchange symbol, home currency with its marker, USD market cap (BUILD.md "Non-US listings").

**M. Plain language** (Oki, 13 Oct 2026). Write for the Reader in CLAUDE.md: a smart adult who doesn't follow markets. No trading-desk shorthand: "marginal price-setter", "float slice", "passive base", "index complex", "reflexive", "register", "constituent", "mandate", "structural bid", "re-rating"/"de-rating", "multiple compression", "operating leverage", "the tape", "compounder", "turns", unexplained "bps", "leveraged proxy for … sentiment", "conviction positions". Say what happens in plain words ("index funds buy and hold whatever is in the index, so active investors move the price day to day"); explain a finance term in a clause on first use; card titles plain too ("Index Funds", not "The Index Complex"). A plain rewrite keeps the claim exactly: "overwhelmingly index-driven" is not "most shares are held by index funds" (the top holders are usually 15–30% of the shares); say "the largest holders are the big index-fund managers". If a sentence needs a finance degree to parse, rewrite it.

**N. Corrections of the previous edition** need a fetched page that contradicts the old figure, named in the delta box; a silent page or a failed fetch is not grounds (MTB, VRSN). Check a `fix_points` change against a primary print before calling it a correction (EL.PA, IBE.MC). Checkers re-check every claimed correction.

**Refreshes (29 Oct 2026).** Re-check carried-over holders, peer caps (recompute), segments and analyst calls, not just bios. Section 05 from a ratings table read at the banner date: every post-print call, prior → new target from the table. Move each "latest quarter"/"now" sentence to the new quarter or date it. Read the 8-Ks and news since the previous banner date. Rule M covers old text.

**Working economically** (each tool call re-sends everything read so far): read the report once in full, then look things up with Grep or a Read with offset/limit — never re-read the whole file; fetch each source once and keep what you need in a temp file; one command per Bash call. **Batch your edits**: put every numeric replacement (prices, ratios, dates, chart arrays) in one Python script with a list of exact old → new pairs, run it once, and check each pair matched exactly once — not one Edit call per number (2 Oct 2026: JBL and FDS builders spent 51 and 61 separate edits). Use Edit for prose.

**Processes.** Stop only what you started, by its PID (`taskkill //PID <n>` or `kill <n>`). Never `taskkill /IM python.exe`, `/IM node.exe`, `/IM chrome.exe` or any kill by name: other agents' servers and Oki's own processes run on this machine (8 Oct 2026).

**Recomputed figures and membership (8–9 Oct 2026).** When `index_rank.py` or `index_stats.py` changes a rank or an index cell, sweep the page's Context cells and prose for the old value or comparison ("vs S&P 500 ~22×", "#2 globally") and recompute or drop it. Explain every term on first use, including on indicator and spin-off pages (spin-adjusted, pro forma, pp, SEP). Index membership is not static: before a run, check S&P DJI and Nasdaq index announcements since the last run and update the cards (`data-sp`, `data-ndx`) first.
