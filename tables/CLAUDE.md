# tables/ — Pillar 02, "The Tables"

Moved from the root CLAUDE.md on 25 Sep 2026 so it loads only when working under `tables/`. Root rules still apply.

- `tables/` — Pillar 02, "The Tables" (Sep 10 2026). `casino-games.html` is the index: grade board, game cards, method, outro. One page per game — `blackjack.html`, `video-poker.html`, `craps.html`, `baccarat.html`, `ultimate-texas-holdem.html`, `three-card-poker.html`, `roulette.html`, `slots.html` — each with the full analysis (how it plays, house edge bet by bet, best/worst bets, quirks, advantage play with legality/acceptance, Gent's Grade) and a **variance simulator** (slots gets a note explaining why there isn't one). Shared chrome in `tables/tables.css`. **The pages are generated**: `py -3 tables/build_tables.py` rebuilds all ten (the eight game pages, Blackjack Variants and the index) from `tables/_source/casino-games-source.html` (the prose source of truth) — edit the source and rebuild, don't hand-edit the outputs. Each game's grade, board one-liner, simulator intro and session length live on its `Game` record in `GAMES` (`tables/game_list.py`); a sentence the builder patches into the source prose fails the build, naming it, if the source wording changes. Builder tests: `py -3 -m unittest discover -s tables/tests`. Figures are published game math; no operators named; keep both disclaimers.
- `tables/sim/games.js` — every bet as an outcome table `{p, x}` in units of the first bet; `kind: "exact"` (from the game's combinatorics) or `"approx"` (a shape calibrated at load to the published edge; labelled in the UI). `tables/sim/ttg-sim.js` — the engine (analytic EV/SD, seeded Monte Carlo, 1,000 sessions, empirical 70%/95% bands, drawdowns, canvas chart, URL-hash state `#bet=…&unit=…&n=…&seed=…`). Vanilla JS, no dependencies. Cross-check after any table edit: every computed edge must match its `edge` field (node one-liner in the 10 Sep vault log).
- `tables/blackjack-variants.html` — Blackjack Variants (Sep 10 2026): Free Bet, Switch, Spanish 21, Double Exposure, Super Fun 21 — generated by the builder from the `blackjack-variants` section of the source (`FAMILY_PAGES` in the builder: family pages that are not on the grade board), with its own simulator tables (`blackjack-variants` in games.js, all approximate/calibrated). The three blackjack pages share a `.famtabs` strip (Blackjack · Variants · Trainer) — `FAMILY` in the builder; the trainer page carries it by hand.
- `tables/blackjack-trainer.html` — Blackjack Trainer (Sep 10 2026): a hand-written page (not generated; own stylesheet `tables/sim/bj-trainer.css`) mounting `tables/sim/bj-trainer.js` (rules → shoe → basic strategy generated from the rule set → pluggable counting systems, Hi-Lo first, with the Illustrious 18 + Fab 4 index plays) and `tables/sim/bj-table.js` (round flow, bot players, timed dealing, play / count-drill modes, count check, strategy + counting-guide + stats panes; settings in localStorage `ttg-bjt`; options for busted-hand removal delay, running-count prompts every N hands, true-count prompts every N cards dealt; a discard-tray / shoe-gauge visual with the cut card — the numeric cards-left readout shows only with the live count on; chip betting: a bankroll rack of TTG chips ($1/5/25/100/500), click a pile to add to the targeted circle, click a stack in a circle to remove its top chip, payouts animate as chips, last bet auto-re-placed after settlement, rebuy when broke; optional bonus circle for 21+3 or Perfect Pairs paid from a fixed paytable; an **Edge** tab (Sep 11 2026) built on the EV engine in bj-trainer.js — `evEngine(rules, tc)` is infinite-deck and composition-independent but re-run per half-point of Hi-Lo true count with the card distribution the count implies (`distFor`), giving action EVs, `startEv` for any two-card deal, the base edge (adjusted per deck count in `DECK_ADJ`) and the insurance EV. Every play-mode decision is priced at the count and classified ok / strategy error (worse than basic strategy) / count deviation captured / count deviation missed; each hand records the true count it was bet into and the EV of the dealt cards, so the pane shows basic strategy by the book vs as-played, the shoe's edge this session, the player's actual edge, **expected value three ways** (1 unit flat, count-optimal ramp, the player's sizing — each under book play and the player's play), deal luck vs draw luck vs result, and the costliest mistakes. A **Hand values** pane shows every two-card start's EV at the current count. With the live count on: running-count badge on the felt, true count in the gauge row, ±1 tags on every visible card. A per-hand decision log under the action buttons grades each action vs basic strategy and vs the count, with perfect-play EV, chosen-action EV and net for mistakes). Add a counting system by adding an entry to `BJT.SYSTEMS`. Linked from `blackjack.html` and the index card.
- `tables/craps-table.html` — the Craps Table (Sep 2026): a hand-written page (not generated; own stylesheet `tables/sim/craps-table.css`) where you place bets on a drawn felt and roll. `tables/sim/craps-engine.js` holds the rules and prices every bet exactly (fractions, not simulation): house edge per bet, and each bet's value in every game state, so the luck readout is settled results plus the change in value of the bets still working. `tables/sim/craps-table.js` is the table and its panels. Check after any engine edit: `node tables/tests/craps_engine_check.js` (every edge against `games.js` and the table on `craps.html`, and the value step for every bet in every state under 64 rule sets). Live, not yet linked from the site.
